# tagalog-shorts

Low-poly 3D Tagalog documentary shorts (9:16, 1–2 min), built with Remotion + three.js.

**Start here:** [HANDOFF.md](HANDOFF.md). It covers the style rules, the approved workflow, the audio levels and the environment gotchas.

- `videos/isang-butil/`: first video, "Isang Butil" (One Grain). Its `video/src/kit.tsx` holds the reusable 3D kit (toy people, terraces, sky, camera).

Audio and voice recordings are not committed. Keep the narrator's original `.m4a` files yourself.
